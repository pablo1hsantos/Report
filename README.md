# Report Operacional In-Haus — v13

Página estática para Vercel. O arquivo `index.html` deve ficar na raiz do repositório `pablo1hsantos/Report`.

## Destino do compartilhamento

Grupo indicado no aplicativo: **⚫ GPS - Supervisão Jonathan**.

O botão prepara a mensagem e abre a escolha de conversas no WhatsApp (`https://wa.me/?text=...`). A pessoa que preenche o report deve escolher manualmente o grupo e confirmar o envio. A URL não permite direcionar para um grupo usando o nome do grupo; nenhuma mensagem é enviada em segundo plano.

## Publicação

Faça commit do novo `index.html` na branch de produção do GitHub conectada à Vercel. O projeto não exige etapa de build.
